# 도입 체크리스트

## 적용 전

- [ ] `AGENTS.md`의 조직·저장소·스택·완료 기준을 팀 상황에 맞췄다.
- [ ] `HARNESS_TEST_COMMAND`로 실제 테스트가 통과한다.
- [ ] `profiles/`의 허용·차단 명령을 보안 담당과 검토했다.
- [ ] 공개 파일에 비밀값, 내부 주소, 개인 경로가 없다.

## 도구별

- [ ] Claude Code가 `.claude/settings.json`을 읽고 위험 명령을 차단한다.
- [ ] Codex CLI가 `.codex/config.toml`과 `.codex/hooks.json`을 읽는다(프로젝트 신뢰 필요). 대화형 `/hooks`에서 훅 정의를 **신뢰 승인**했다.
- [ ] 사용하는 경우 Gemini 설정의 `# ⚠️ 미확인:` 항목을 현재 버전에서 확인했다.
- [ ] `skills/release-notes/SKILL.md`가 필요한 요청에서 발견된다.

## 5분 확인

- [ ] 새 세션에서 프로젝트 지침을 요약시켰다.
- [ ] 안전한 읽기와 테스트는 승인 없이 통과한다.
- [ ] 모의 강제 푸시 문자열은 실행 전에 차단된다.
- [ ] Stop 게이트가 실패를 막고 성공 뒤 상태 파일을 지운다.
- [ ] `metrics/kpi.js`가 세션 디렉터리에서 표를 출력한다.
