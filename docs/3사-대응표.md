# 3사 대응표

## A1 — 시작·설정 위치

| 하려는 일 | Claude Code | Codex CLI | Gemini CLI |
|---|---|---|---|
| 실행 | `claude` | `codex` | `gemini` |
| 프로젝트 지침 | `CLAUDE.md` | `AGENTS.md` | `GEMINI.md` |
| 프로젝트 설정 | `.claude/settings.json` | `.codex/config.toml` | `.gemini/settings.json` |
| 승인·안전장치 | permission mode | `approval_policy`·`sandbox_mode` | 정책 엔진 |

# ⚠️ 미확인: Gemini CLI의 인증·정책 엔진·설정 스키마는 설치 버전에서 재검증합니다.

## A2 — 지침 계층

| 하려는 일 | Claude Code | Codex CLI | Gemini CLI |
|---|---|---|---|
| 프로젝트 지침 | `CLAUDE.md` | `AGENTS.md` | `GEMINI.md` |
| 하위 지침 | 하위 `CLAUDE.md` | 하위 `AGENTS.md` | 하위 `GEMINI.md` |
| 상위 지침 대체 | 명시 지침 | `AGENTS.override.md` | 명시 지침 |
| 반영 주의 | 세션 중 수정 뒤 `/clear` 또는 재시작 | `project_doc_max_bytes` 기본 32KiB | 설치 버전 확인 |

# ⚠️ 미확인: Claude의 `@path` 임포트와 Gemini의 `contextFileName` 키는 재검증합니다.

## A3 — 명령·스킬

| 항목 | Claude Code | Codex CLI | Gemini CLI |
|---|---|---|---|
| 명령 | `.claude/commands/*.md` | 커스텀 프롬프트 대신 스킬 | `.gemini/commands/*.toml` |
| 스킬 | `SKILL.md` | `.agents/skills/*/SKILL.md`, `$skill` | 확장의 `skills/` |
| 배포 | 플러그인 또는 저장소 | 설정·스킬 공유 | Extension |

# ⚠️ 미확인: Gemini 명령·스킬·Extension 로드 규칙은 설치 버전에서 재검증합니다.

## A4 — 역할별 에이전트

| 항목 | Claude Code | Codex CLI | Gemini CLI |
|---|---|---|---|
| 정의 위치 | `.claude/agents/*.md` | `.codex/agents/*.toml` | `.gemini/agents/*.md` |
| 형식 | Markdown과 frontmatter | TOML | Markdown과 frontmatter |
| 공통 설정 | 에이전트 frontmatter | `[agents]` | 에이전트 frontmatter |
| 동시 실행 | 지원 | `max_concurrent_threads_per_session` | 프리뷰 |

# ⚠️ 미확인: Gemini 병렬 에이전트와 frontmatter 필드는 설치 버전에서 재검증합니다.

## A5 — 권한·훅

| 하려는 일 | Claude Code | Codex CLI | Gemini CLI |
|---|---|---|---|
| 실행 범위 제한 | permission mode와 샌드박스 | `sandbox_mode` | 정책 엔진과 `excludeTools` |
| 승인 시점 | permission mode | `approval_policy` | 정책 규칙 |
| 훅 설정 | `.claude/settings.json` | `.codex/hooks.json` | 확장 훅 파일 |
| 대표 이벤트 | `PreToolUse`, `PostToolUse`, `Stop` | `PreToolUse`, `PostToolUse`, `Stop` | 설치 버전 확인 |
| 차단 | exit 2 또는 JSON(`permissionDecision: deny`, Stop은 `decision: block`; `PermissionRequest`는 `decision.behavior`) | exit 2 또는 JSON(`permissionDecision: deny`, Stop `decision: block` — exit 0이면 stdout은 JSON만) | 설치 버전 확인 |
| 훅 활성화 | 설정에 등록하면 실행 | 등록 후 `/hooks`에서 신뢰 승인(정의 변경 시 재승인) | 설치 버전 확인 |
| 되돌림 | `/rewind`(Edit/Write 변경만) + git | git만(`/rewind` 없음, 대화는 `/fork`) | 설치 버전 확인 |

# ⚠️ 미확인: Gemini 훅 스키마는 설치 버전에서 재검증합니다. (Codex matcher는 도구 이름 정규식 — 2026-10-04 문서 확인)
