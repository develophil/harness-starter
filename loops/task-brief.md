# 작업 지시문

## 목표

한 문장으로 완료 상태를 씁니다.

## 대상

- 수정 허용: 파일이나 디렉터리를 나열합니다.
- 수정 금지: 테스트 기준 파일, 데이터, 보호 경로, 비밀 파일을 나열합니다.

## 완료 판정 기준

1. 기계가 실행할 명령과 기대 종료 코드를 씁니다.
2. 경계 사례와 회귀 확인 범위를 씁니다.
3. 허용 범위 밖 변경이 없음을 확인하는 명령을 씁니다.

## 상한

- 시도 5회 또는 20턴 중 먼저 오는 시점에 중단합니다.
- 같은 지점에서 2회 연속 실패하면 원인 가설과 시도 내역을 보고합니다.

## 보고 형식

1. 결론
2. 변경 파일
3. 검증 상태
