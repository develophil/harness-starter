## 집계 정의

`node metrics/kpi.js <디렉터리>`는 하위 폴더의 `.json`·`.jsonl`을 읽습니다. Claude 헤드리스 결과는 결과 레코드별, 실제 트랜스크립트(`type=assistant`, `message.usage`)는 파일별로 세션 하나를 셉니다. 같은 `message.id`의 여러 블록은 한 번만 집계합니다.

Claude 캐시 히트율은 `cache_read_input_tokens / (input_tokens + cache_creation_input_tokens + cache_read_input_tokens)`입니다. Codex의 `cached_input_tokens`와 기존 가상 로그의 `cache_read_tokens`는 이미 전체 `input_tokens`에 포함된 값이므로 분모에 다시 더하지 않습니다.

명시된 개입 횟수가 없을 때 `permission_denials` 수를 사람 개입 열의 **대리지표**로 씁니다. 이는 승인 거부 수이며 실제 사람의 승인·재지시 수와 다릅니다. 트랜스크립트 반복 수는 `stop_hook_summary` 중 `hookErrors`가 있는 행의 수입니다. 비용·개입·반복·되돌림 근거가 없으면 `—`로 표시하며 가격표로 비용을 추정하지 않습니다.
